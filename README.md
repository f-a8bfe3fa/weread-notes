# 📖 微信读书笔记自动同步工具(小白专属配置指南-模版极速版 v6)

## 🌟 **写在前面：**

这是一个专门为**完全不懂计算机的小白**准备的超详细安装指南！

原版文档有很多专业的命令行操作（比如 Git、Pip 等），在这里我们**通通不需要**！你只需要跟着下面的视频步骤，用鼠标点击、复制、粘贴，就能轻松搭建属于你自己的**微信读书 \-\> Notion \+ GitHub 个人私有笔记库**！



## 这个工具能做什么？



简单来说，它能帮你：



- **自动拉取**你在微信读书里做的划线、想法、书评

- **保存到 GitHub** 仓库，永久备份，不怕丢失

- **同步到 Notion**，方便整理、搜索、分享

- **每天自动运行**，自动同步笔记，不用你操心



---



## 🧭 准备工作



在正式开始配置之前，请先注册并登录以下三个账号：

1. **GitHub 账号**（用于存放备份文件和自动运行同步程序）

2. **微信读书账号**（用于获取你的读书笔记）

3. **Notion 账号**（用于精美展示和整理你的笔记）

## [🎬 详细配置步骤（可以跟随视频一步步来）](https://www.bilibili.com/video/BV19B4X63EcD/?share_source=copy_web&vd_source=7c6ec3f3af94f35847bcff21c07d5800)




### 第一步：一键使用模板创建并清理你的 GitHub 私人仓库


为了保护你的阅读隐私，我们需要通过官方的“模板克隆”功能，把所有项目内容一键复制到你自己的“私人保险箱”里，并把作者以前的测试数据清理干净。

#### 1. 一键克隆模板[(项目地址)](https://github.com/f-a8bfe3fa/weread-notes)
* 访问本项目（作者的原始项目）主页。
* 在网页右上角，找到并点击绿色的 **「Use this template」**（使用此模板）按钮。
* 在下拉菜单中选择 **「Create a new repository」**（创建新仓库）。

#### 2. 配置你的新仓库
* **仓库所有者（Owner）：** 保持是你自己的 GitHub 账号不变。
* **仓库名称（Repository name）：** 可以起一个好记的名字（例如：`weread-notes`）。
* **可见性（Visibility）：** **一定要勾选 「Private」（私有）**！这样别人就绝对看不到你的读书笔记了，安全第一。
* **其他选项：** 默认即可，不用勾选其他的多余选项。
* 点击最下方的绿色 **「Create repository from template」** 按钮。
* 稍等几秒钟，GitHub 就会自动把原项目的所有代码（包括隐藏的后台自动运行配置文件）完整克隆到你的私有仓库中了！你会看到仓库名旁边多了一个锁的标志，代表这是你的私人仓库。

#### 3. 清理原仓库的测试数据（极其重要！🌟）
> **为什么要清理？** 克隆模板会把作者以前测试留下的读书笔记（`data` 文件夹和 `index.json` 索引文件）也原封不动地复制到你的仓库中。如果不删掉它们，这些测试书籍就会混进你自己的 Notion 笔记库，且干扰你自己的数据同步。
> 
> **极简清理步骤（直接在网页端删除，无需任何复杂工具）：**
> 1. **删除 `index.json` 文件：**
>    * 在你新建的 GitHub 仓库主页，点击 **`index.json`** 文件进入。
>    * 点击右上角的 **垃圾桶图标（Delete file）**（或者点击 `...` 展开菜单并选择 **Delete file**）。
>    * 点击下方的绿色 **「Commit changes...」** 按钮，再点击确认，即可成功删掉该文件。
> 2. **清理 `data` 文件夹里的测试书籍：**
>    * 回到你的仓库主页，点击进入 **`data`** 文件夹。
>    * 里面是作者留下的测试书籍文件（一般是一两个 `.json` 文件）。依次点击它们进入文件页面，同样点击右上角的 **垃圾桶图标（Delete file）** 逐个删除并 **Commit changes** 提交。
> 
> *（温馨提示：当 `data` 文件夹里的所有测试文件被全部删完后，GitHub 会自动隐藏这个空的 `data` 文件夹，因为 Git 无法追踪空文件夹。不用担心，等一会儿程序开始自动同步时，会自动为你重新生成只属于你自己的、干净的 `data` 文件夹！）*
>

### 第二步：获取你的微信读书密钥 \(Key\)



我们需要一把“钥匙”来读取你的微信读书笔记。



1. 登录 [微信读书网页版](https://weread.qq.com/)。

2. 点击你的头像。

3. 再点击 **「微信读书 skill」**

4. 翻到最下面，找到并**复制这一串 Key**。

5. 临时新建一个文本文件（记事本），把这个 Key 粘贴保存好，等会儿要用。

    

---



### 第三步：配置 Notion 模板与集成



让笔记漂亮地同步到你的 Notion 数据库中！


#### 1\. 复制[Notion模板](https://bubble-sodium-5ed.notion.site/362e809a4d8b80f89245e3582fded80a?v=364e809a4d8b8034be53000cd463a87d&source=copy_link)


- 在原项目网页右侧，找到 **Notion 模板链接** 并点击打开。

- 页面加载完后，点击右上角的 **「Duplicate」**（克隆/复制）按钮，将这个模板复制到你自己的 Notion 工作区中。

    

#### 2\. 清理模板中的测试数据

- 进入你刚刚克隆好的 Notion 页面，你会看到几条作者留下的测试笔记，**直接全选并删除**它们。我们需要一个干净的空白数据库来存放你自己的笔记。

    

#### 3\. 创建 Notion 机器人（集成/Integration）

- 访问 Notion 的开发者门户：[Notion My Integrations](https://www.notion.so/my-integrations)。

- 点击 **「\+ New integration」**（新建集成）。

- 给它起个名字（例如：`微信读书同步`），然后点击 **「Submit」** 提交。

- 提交后，你会看到一串 **「Internal Integration Token」**（内部集成令牌，以 `secret_` 开头）。点击 **「Copy」** 复制它，并记录在你的记事本中，这叫做 **Notion API Key**。

    

#### 4\. 把机器人关联到你的 Notion 页面

- 回到你刚刚克隆的 Notion 数据库页面。

- 点击右上角的 **「\.\.\.」**（省略号按钮）。

- 往下翻，找到 **「Connections」**（连接）或 **「Add connections」**（新增连接）。

- 搜索你刚刚创建的机器人名字（如：`微信读书同步`），点击添加并同意关联。这一步至关重要，否则机器人无法把笔记写进你的页面！

    

#### 5\. 获取 Notion 数据库 ID

- 看看你当前 Notion 数据库页面的浏览器地址栏（URL）。

- 它的格式通常是 `https://www.notion.so/你的用户名/一串字母数字?v=一串字母数字`。

- **斜杠 ****`/`**** 后面、问号 ****`?`**** 之前的这一长串 32 位的字母数字**，就是你的 **Notion Database ID**。把它复制并记录到记事本里。

    

---



### 第四步：配置 GitHub Secrets（填入安全钥匙）



现在我们要把记事本里的“三把安全钥匙”安全地存放到 GitHub 中，让自动运行的程序能够使用它们。



1. 回到你在 GitHub 上刚刚创建的私有仓库页面（可以看到有一个锁的标志，代表私有）。

2. 点击仓库上方的 **「Settings」**（设置）选项卡。

3. 在左侧菜单栏中往下翻，找到 **「Secrets and variables」**，点击展开后选择 **「Actions」**。

4. 点击右上角绿色的 **「New repository secret」**（新建仓库密钥）按钮。

5. 我们需要依次添加以下 **3 个密钥**（每次添加一个，名字填在 `Name` 里，内容填在 `Value` 里，然后点击 Add secret 保存）：

    

|密钥名称（Name）|对应填入的内容（Value）|
|---|---|
|**`WEREAD_API_KEY`**|你在第二步中复制的 **微信读书 Key**|
|**`NOTION_API_KEY`**|你在第三步中获得的 Notion **Internal Integration Token**|
|**`NOTION_DATABASE_ID`**|你在第三步中提取的 Notion **Database ID**|



---



### 第五步：配置自动运行工作流 \(GitHub Actions\)


由于我们使用的是模板克隆，所有的自动运行文件已经完美躺在你的仓库里了，你 **完全不需要手动复制代码**！

不过，**GitHub 默认会对克隆/复制过来的项目的 Actions 工作流进行禁用（Disabled）**。为了让这些工作流能够全自动定时运行，我们需要进行一次手动的激活与初始化。

在这个新版工具中，我们为你配置了 **3 个全自动工作流**：
1. **代码自动更新工作流（Auto Update Code）：** 🌟 自动拉取原作者最新更新的代码，让你的工具永远保持在最新版本，实现“一次配置，终身无忧”！
2. **每日运行的工作流（Daily WeRead Sync）：** 每天定时增量同步，快速获取新划线和想法。
3. **每月运行的工作流（Monthly Full WeRead Sync）：** 🌟 **最新升级：** 以前是每周运行，但因为微信读书的 API 进行了规则调整，全量同步的运行时间变长。为了避免不必要的频繁请求导致接口不稳定，现已**优化调整为每月自动运行一次全量同步**（用于精准地检测并同步你对历史笔记、想法/书评的修改）。


        

#### 🚀 极速激活步骤（请严格按照以下顺序操作）：

在你的 GitHub 仓库上方，点击 **「Actions」**（操作）选项卡。你会看到左侧列出的工作流。因为默认是禁用的，我们需要通过手动触发来唤醒它们：

1. **第一步：激活「代码自动更新工作流」（Auto Update Code）**
   * 在左侧选择 **「Auto Update Code」** 工作流。
   * 在右边点击 **「Run workflow」**（运行工作流）按钮，再点击绿色的 **Run workflow** 确认。
   * 它运行速度极快，**大概几秒钟就会成功结束**（圆圈变成绿色对勾）。

2. **第二步：激活「每日运行的工作流」（Daily WeRead Sync）**
   * 在左侧选择 **「Daily WeRead Sync」** 工作流。
   * 点击右边的 **「Run workflow」**。
   * **重点：这里完全没必要等它运行成功！** 让它运行大约 **1 分钟左右** 之后，直接手动点击 **「Cancel run」**（或在运行详情里选择取消运行）把这个工作流手动关闭。
   * *注：我们手动点击并让它跑 1 分钟的唯一目的，是为了**激活/打开这个工作流的自动运行开关**。只要被成功唤醒过一次，后续它就会自动在后台静默定时运行，我们不需要干等它跑完。*

3. **第三步：运行并完成「每月运行的工作流」（Monthly Full WeRead Sync）**
   * 在左侧选择 **「Monthly Full WeRead Sync」** 工作流。
   * 点击右边的 **「Run workflow」**。
   * 触发它运行以后，**你就可以直接关闭网页，完全不用管了！** 程序会在后台全自动、慢慢地将你所有的历史读书笔记和划线同步到 Notion 中。至此，你的所有配置任务就已经圆满结束了！

        

🎉 **大功告成！** 

现在，小工具已经彻底配置完毕。以后，它会在每天早上**自动帮你把微信读书的新笔记、新划线和想法同步到 Notion 和 GitHub**，你再也不需要手动做任何操作了！

## 💡 进阶小贴士（适合笔记超级多的朋友）



如果你的一个非常热爱读书的人，那你微信**读书笔记一定非常多（成千上万条）**，第一次全量同步可能会因为耗时太长而中途断开。



你可以做如下优化：

1. 在你自己的 GitHub 仓库中，找到并点击打开 `.github/workflows/manual-full-sync.yml` 文件。

2. 点击右上角的画笔图标（编辑文件）。

3. 视频中，作者将时间限制设置为了 `360` 分钟。如果你的笔记量极大，建议将这个数值改大，这样同步过程就不会因为超时而意外中断，确保所有笔记能一次性顺利拉取下来！

4. 修改后点击 **「Commit changes\.\.\.」** 保存即可。
